# 后台品牌与期刊页面切换

后台采用温禾米与归安赭作为品牌配色。按用户确认的归安赭 Y89 实施。

| 品牌色 | CMYK | 屏幕近似色 | 使用位置 |
| --- | --- | --- | --- |
| 温禾米 | C12 M13 Y19 K0 | `#DED4C8` | 工作区大面积背景 |
| 归安赭 | C56 M83 Y89 K37 | `#5E3229` | 主按钮、选中标签、导航标识、焦点强调 |

CMYK 是印刷色；网页以用户提供的品牌色卡图片的主色块作为屏幕显示参考，避免无 ICC 配置的直接换算带来偏绿或过深的颜色。后续提供品牌 RGB 色值时，可直接调整 `admin-theme.css` 的两个品牌变量。

动作按钮由 `admin-controls.css` 统一：常规操作高 44px、圆角 6px、组内间距 8px；主要表单操作至少 112px 宽，表格行操作至少 64px 宽，纯图标工具为 44×44px。主按钮为归安赭实底，次按钮为白底赭色描边，禁用、危险与焦点状态分别保留。表单底部操作靠右，表格行操作不折行，窄屏表单按完整按钮换行。

桌面端会员列表将整组行操作固定在表格右侧，数据列仍可横向滚动；手机端保留完整表格滚动，不让固定操作栏挤占内容。

白色卡片和侧栏用于保证层次与文字清晰度。辅助面、边框和文字使用同一米赭色系的浅深变化；成功、警告、错误保留语义色。手机预览内的已发布内容和富文本颜色由内容自身控制。

期刊中具有两个页面的栏目（人物故事、微声音），均在工作区顶部使用同一个“编辑页面”切换栏。人物故事为“首页入口／详情页”，微声音为“列表页／详情页”。单页栏目不显示无意义的切换按钮。

移除微声音手机预览标题旁的切换按钮，以及人物内容卡片里的重复详情入口。切换栏支持左右方向键、Home、End 和焦点状态；切换不保存、不发布，也不清空草稿。点击手机预览内的条目仍能自然进入相应详情。
