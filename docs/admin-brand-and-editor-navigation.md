# 后台品牌与期刊页面切换

后台采用温禾米与归安赭作为品牌配色。按用户确认的归安赭 Y89 实施。

| 品牌色 | CMYK | 屏幕近似色 | 使用位置 |
| --- | --- | --- | --- |
| 温禾米 | C12 M13 Y19 K0 | `#E0DECF` | 工作区大面积背景 |
| 归安赭 | C56 M83 Y89 K37 | `#471B12` | 主按钮、选中标签、导航标识、焦点强调 |

CMYK 是印刷色；当前网页以常规 CMYK→RGB 换算作为近似显示。若后续提供指定 ICC 配置或品牌 RGB 色值，可直接调整 `admin-theme.css` 的两个品牌变量。

白色卡片和侧栏用于保证层次与文字清晰度。辅助面、边框和文字使用同一米赭色系的浅深变化；成功、警告、错误保留语义色。手机预览内的已发布内容和富文本颜色由内容自身控制。

期刊中具有两个页面的栏目（人物故事、微声音），均在工作区顶部使用同一个“编辑页面”切换栏。人物故事为“首页入口／详情页”，微声音为“列表页／详情页”。单页栏目不显示无意义的切换按钮。

移除微声音手机预览标题旁的切换按钮，以及人物内容卡片里的重复详情入口。切换栏支持左右方向键、Home、End 和焦点状态；切换不保存、不发布，也不清空草稿。点击手机预览内的条目仍能自然进入相应详情。
