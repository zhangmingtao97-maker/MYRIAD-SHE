# 动效与交互优化验证

## 实现范围

- 实践页：首次读取显示静态骨架；再次刷新保留目录，合并重复请求，失败原位重试；隐藏与卸载后忽略旧响应。
- 声音：首页与详情分开表达准备、播放、缓冲和失败；依据播放器事件显示实际播放状态，等待期间可取消；失败重建播放器，离页销毁并隔离旧回调。
- 观察保存：使用固定的同步状态区域，保留已保存反馈，避免状态消失引起按钮跳动；后台保存栏同步区分保存中、未保存、已同步和冲突。
- 首页：人物、声音、问题、引言与页尾首次进入视野时轻量入场，刷新保留完成状态；图片加载成功后淡入，忽略过时图片回调；页尾花形只舒展一次。
- 后台：期刊媒体、日常之物及品牌图采用真实上传进度；传输达到 100% 后仍等待服务器成功响应；失败、超时及取消单独反馈。退出会话或卸载后中止上传。原媒体清理流程保留。
- 排序：实践目录、期刊栏目选择器和手机预览采用 Vue TransitionGroup 平滑换位。
- 减少动态效果：新增动画提供 reduced-motion 降级；首页观察器不支持时内容仍可阅读。

## 验证入口

- `backend/`：`npm run test:unit`，含实践刷新与响应隔离、音频缓冲/取消/重试、首页入场与图片加载状态回归。
- `management/`：`npm run build`、`npm run test:admin`。
- `management/`：`npm run test:media-feedback`，以真实本地 HTTP 上传验证进度、服务器确认、HTTP 失败、超时、取消、无管理员凭据泄漏、保存状态、375px 布局及减少动态效果。
- 使用本机微信开发者工具附带的 WXML/WXSS 编译器检查四个修改页面；编译产物仅保存于 `.codex-artifacts/`。

## 后续整改（第 2—6 项）

- 首页阅读连续性：对比内容与媒体路径，签名查询参数变化不重绘；同一期按栏目更新，保留图片、入场与播放状态。新一期先提示，经用户点击再切换并回到页首；后台刷新失败继续保留当前阅读。
- 声音恢复：首页和声音详情共用 `recoverable-audio.ts`，12 秒缓冲期限不会被重复等待事件延长；超时或播放错误后，按原期号、模块和音轨重新获取地址一次，从原位置续播，再次失败允许手动重试。暂停、离页与销毁会取消恢复，旧播放器回调无效；声音列表、详情和分享路径携带期号。
- 返回与失败恢复：观察列表返回时保留已加载页数、记录和滚动位置，刷新失败原位重试；账号变化立即清除旧记录。观察草稿在同一账号会话、同一云端修订内记住所在步骤及四时子步骤，仅存内存且不含答案；修订变化回退到按答案恢复。昵称保存失败保留输入并重新打开编辑框，换账号清除输入。
- 后台保存与发布：实践页明确显示待发布草稿，记录成功保存时间；期刊区分保存草稿与整期发布，并校验服务器保存回执、发布版本。期刊和实践页新增“查看线上内容”，从公开发布接口独立读取，支持读取失败重试，关闭后返回原按钮焦点。
- 模块拆分：上传状态与中止控制移入 `useMediaUploads.ts`；请求期限与错误消息移入 `admin-api.ts`；发布状态和线上预览拆为独立 Vue 组件。编辑、媒体回收和发布权限仍使用原有业务流程。

新增验证覆盖：新一期确认切换、离线保留、媒体地址签名与换源、原期刊声音地址刷新、超时续播及取消、观察分页与位置恢复、草稿步骤和账号隔离、昵称失败重试；浏览器以真实本地 HTTP 验证上传 composable、保存/发布反馈、线上预览失败重试、关闭焦点、375px 布局。

## 本轮验证结果（2026-11-13）

- 单元与页面逻辑测试：320 项通过。
- 后台完整交互回归：32 个授权入口及三种视口通过。
- 媒体反馈与线上预览：真实本地 HTTP 上传、实践/期刊线上快照、失败重试、对话框焦点恢复通过。
- 后台 TypeScript/Vite 构建通过；仍有既有的大体积打包提示。
- 七个涉及页面的 WXML/WXSS 编译通过；产物位于 `.codex-artifacts/continuity-wxml.js`、`.codex-artifacts/continuity-wxss.js`。
