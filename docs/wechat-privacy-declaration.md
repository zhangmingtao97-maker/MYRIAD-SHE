# 微信隐私保护指引配置与验收

依据：[关于小程序隐私保护指引设置的再次公告](https://mp.weixin.qq.com/wxopen/announce?action=getannouncement&announce_id=1694692148&version=23&lang=zh_CN)、[小程序隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)、[小程序用户隐私保护指引内容介绍](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)。核对日期：2026-11-13。

## 代码内政策与平台声明分别维护

应用内《隐私政策》通过管理后台的协议与隐私管理发布。2026-11-13 修订正文见 [privacy-policy-2026-11-13.html](privacy-policy-2026-11-13.html)，补充账户标识、头像昵称、图片、手机号登录、地址、云端保存、授权与撤回说明，保留观察私密和讨论经历处理规则。

微信接口权限取决于公众平台登记的《小程序用户隐私保护指引》。仅修改上述正文、上传代码、配置 MinIO 或调整 app.json 都不能替代平台声明。

## 公众平台填写内容

入口：微信公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引。按当前代码实际使用填写以下信息类型与用途，保留后台登记的真实开发者主体及有效联系方式。

| 平台信息类型 | 实际接口或组件 | 用途文案 |
| --- | --- | --- |
| 收集你的昵称、头像 | `button open-type="chooseAvatar"`、`input type="nickname"` | 为完善及修改账户资料，在你主动选择头像、选用微信昵称或自行输入昵称后，保存并展示头像和昵称，用于账户身份区分。 |
| 收集你选中的照片或视频信息 | `wx.chooseMedia`、`wx.chooseImage` | 为设置或更换账户头像，在你主动从相册选择或拍照并确认后，获取并上传所选图片。仅请求图片，不请求视频，不批量读取相册。 |
| 收集你的手机号 | `button open-type="getPhoneNumber"` | 在你主动授权手机号后，用于账户登录、关联与资料管理。手机号用于授权登录并加密保存；无需头像或昵称，拒绝授权仍可浏览公开内容。 |
| 收集你的地址 | `wx.chooseAddress` | 在你主动选择并确认收货地址后，保存收货人、联系电话和地址，用于收货地址管理及你后续确认的相关履约服务。不提供不影响其他功能。 |
| 读取你的剪切板（平台类型名称） | `wx.setClipboardData` | 在你主动点击复制时，将客服联系方式或数据导出内容写入剪贴板，供你粘贴使用；不主动读取或上传原有剪贴板内容。 |

平台将 `wx.setClipboardData` 与 `wx.getClipboardData` 列在同一类型下；本项目只使用前者。当前拍照使用 `chooseMedia/chooseImage`，没有直接调用 `scope.camera` 或 `<camera>`，不要为此额外声明并未使用的摄像头接口。若将来改变实现，按新增接口再补充。

保存期限、信息使用、用户权益与联系方式按平台表单如实填写。账户资料用于账户存续期间的服务；删除申请的处理日期以小程序展示为准。主体全称、有效联系方式等使用账号真实登记信息，不能用品牌名猜测或填占位信息。平台已有内容不应被整份覆盖。

## 授权流程

采用公告允许的隐私同意按钮与手机号授权组件耦合方式：登录按钮使用 `open-type="getPhoneNumber|agreePrivacyAuthorization"`。同意隐私事件本身不创建会话；收到成功的手机号授权回调后，调用 `wx.login` 取得新 code，将 `{ code, phoneCode }` 一起提交 `/auth/wechat/login`。服务端校验 OpenID 和手机号、加密保存手机号后签发 JWT。头像和昵称不参与登录校验，可登录后在个人资料中选填。

已验证手机号的账户，后续会话可按 OpenID 恢复；只有头像昵称、没有验证手机号的账户仍需手机号授权。拒绝手机号授权不登录，用户可以返回公开内容。登录页不调用头像、图片或昵称接口，不展示资料完善弹窗。

登录页与隐私政策页使用 `wx.openPrivacyContract` 打开平台真实指引，应用内隐私政策保留独立入口。平台在需要时展示官方授权弹窗；用户拒绝时不能继续获取相关信息。

`requiredPrivateInfos` 不能当作任意隐私 API 列表；本项目保留合法的 `chooseAddress` 配置，不把 `chooseMedia`、`chooseAvatar`、`getPhoneNumber` 写进去。

## 已确认错误与真机验收

真机返回 `chooseMedia:fail api scope is not declared in the privacy agreement`，对应官方文档的未声明信息类型错误（112）。需要补充“收集你选中的照片或视频信息”；头像昵称和手机号还须分别声明。官方文档说明补充声明约 5 分钟后生效。

保存并使平台指引生效后，等待至少 5 分钟并重新进入预览：

1. 打开平台隐私保护指引，确认上述类型、真实主体和联系方式均已展示。
2. 新用户不选择头像、不输入昵称，点击“手机号授权登录”，确认手机号后直接进入小程序。
3. 拒绝手机号授权时不创建登录会话，可重试或返回浏览公开内容。
4. 空头像、空昵称的已验证手机号账户下次登录不再触发资料填写要求。
5. 登录后个人资料中的头像和昵称均可选填；图片取消或失败不影响已建立的登录会话。
6. 已同意且范围未变的用户不重复要求隐私同意；平台新增范围时按平台返回状态重新授权。
7. 检查收货地址与复制功能，拒绝授权时保留页面可操作性。

源码与模拟器验证不能证明平台声明已生效，最终需要完成上述真机步骤。
